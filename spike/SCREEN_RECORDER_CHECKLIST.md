# Samsung Screen recorder baseline (US-003)

This uses the phone's built-in recorder, not the spike app. It shows what Samsung itself can capture during a WhatsApp call, as a reference point for the spike results.

## Setup

1. Pull down Quick settings › **Screen recorder** (add the tile via ✏️ if it is missing).
2. Long-press the tile › **Sound** › choose the setting for the row being tested.
3. Start recording, then make a WhatsApp voice call.
   - Talk 10 s yourself, then let the other person talk 10 s.
4. Stop the recording, then play the video back from Gallery.
